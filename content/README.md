# Editorial content

This content was authored in the active Codex session from the new, structured 2015 Mustang HTML collection. No earlier site code or articles were reused, and no external AI API was called.

- `glossary.json` contains **153 authored explanations** and **198 separate source-extracted abbreviation expansions**. The expansions are not counted as authored teaching content. Each expansion keeps its original source reference; conflicting expansions would remain separate variants instead of being silently combined.
- **52 glossary terms** include original illustrations inspected during authoring, with precise captions and callouts. A diagram's applicability stays attached to the image. A general definition does not make a 3.7L illustration valid for another engine.
- **55 terms** have category/context constraints to keep ambiguous words such as piston, oil pump, pressure plate, input shaft and pinion from linking to the wrong mechanism.
- `systems.json` gives **13 system introductions** with what/why/how context and references. These are learning aids, not substitute repair procedures. Engine-specific examples are identified in the prose.
- `guides/` contains **eight core complete authored overlays**: electric steering, the 3.7L accessory drive, the 5.0L front crankshaft seal, the 5.2L oil/filter procedure, front 2-piston brake pads, 3.7L cooling, rear suspension, and rear-halfshaft diagnosis. It also contains **four diagram-reviewed overlays** for the 2.3L idler pulley, the 3.7L/5.0L A/C belts and the convertible-top component overview, plus **ten calculator introduction overlays** for the original source calculators. Calculator formulas are implemented and verified separately; their zero editable prose blocks are not counted as rewritten repair instructions.

An overlay edits exact source blocks and retains all original tables, diagrams, nesting and action order. It is accepted only against its current parsed-source hash, with every eligible nonempty text block accounted for. Numeric values, technical identifiers and unchanged-prose checks are run with the same validator used by the ongoing Codex conversion pipeline. `humanReviewed: false` distinguishes Codex authorship and automated checks from a qualified human review.

The front-seal guide follows the **new source**: clean engine oil is specified without importing an oil grade from the previous PDF; the procedure includes a final road test. The oil/filter guide is **5.2L only** and preserves both spin-on and cartridge branches, separate torques, the unused smallest O-ring, and the hand-operated drain-plug instruction. The brake guide is **front 2-piston only** and preserves clip orientation, hose protection, conditional piston retraction and the final fluid check.

Document IDs use the table of contents, not the HTML metadata ID, because metadata identifiers can repeat between engine variants. Source paths are retained for traceability. Glossary roles are centralized; articles link to those explanations instead of maintaining independent definitions. Tool requirements inferred directly from a specified torque/angle operation are identified as capabilities rather than falsely presented as a source-listed special-tool number.

The two A/C-belt overlays explicitly identify source wording inconsistencies instead of silently changing the instructions. Their original illustrations establish which belt is being positioned. The 5.0L accessory-belt seating instruction remains an after-installation check, with its original sequence preserved. These clarifications are Codex interpretations of inspected source text and media, not a qualified human review. The idler-pulley overlay records the original color legend and center-bolt diagram that supply its otherwise image-only removal action.

The convertible-top overlay explains the smart-motor/module naming using the adjacent overview and operation references. Its malformed right-hand side label is clarified explicitly while the original component table remains intact.

General engineering explanations in the added glossary terms were checked against primary supplier references where the workshop page supplies only a component location. Each such entry records its `knowledgeSources` and the limits of those sources; the linked manual remains authoritative for Mustang applicability and repair instructions. Examples include [DENSO receiver driers](https://www.denso-am.eu/products/ac-engine-cooling/receiver-drier), [Garrett turbo-system principles](https://www.garrettmotion.com/it/turbocharger-technology/how-a-turbo-works/basic/), [Bosch direct-injection pumps](https://www.bosch-mobility.com/en/solutions/pumps/high-pressure-pump/), [Gates crankcase ventilation](https://www.gatestechzone.com/gb/en/articles/the-role-of-the-positive-crankcase-ventilation-valve.html), and [NXP LIN networking](https://community.nxp.com/t5/NXP-Tech-Blog/101-Local-Interconnect-Network-LIN/ba-p/1284877). Supplier product ratings, maintenance intervals and aftermarket advice were not carried into the Mustang instructions.

These curated guides do not imply the entire collection has been rewritten. Other articles remain clearly identified as source material until the ongoing Codex process produces an accepted complete overlay.

## Topic teaching context

`topic-contexts.json` adds a plain-language explanation above each mapped reference without changing source blocks. Each entry explains the component or concept, its purpose, and how to understand the particular job, circuit or reference. Shared topics are limited to the same component; wiring sheets and individual connectors receive distinct mappings. Broad engine and transmission topics preserve the exact source section and operation phase. `context-overrides.json` keeps the diagram-reviewed steering-column explanations and exact circuit distinctions as durable editorial overrides.

The API validates every mapping against its parsed-source hash and resolves only existing source and glossary IDs. Context coverage is independent of full instruction rewrites. An explanation at the top does not mean that every instruction below has been rewritten. The reader labels that distinction explicitly. Three centralized steering-column glossary terms include inspected original illustrations.

Run `node scripts/author-topic-contexts.mjs --concurrency 3 --batch-size 24` for the resumable offline Codex authoring workflow. It uses the signed-in Codex CLI, strips external provider API keys from child environments, and never runs generation in the website. `--limit 24` bounds a trial; `--prepare-only` refreshes accepted content without new authoring. Current source hashes, evidence, glossary context and editorial version bind checkpoints. Run `node scripts/audit-contexts.mjs` to require complete corpus coverage.
